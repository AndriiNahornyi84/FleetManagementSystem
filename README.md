# Fleet Management System — LogiTrans s.r.o.

> **Webová aplikácia na riadenie a monitorovanie vozového parku**  
> Практична частина дипломної роботи (TUKE, напрям логістика).

Повноцінний сучасний вебзастосунок для автоматизації управління, обліку та аналітики комерційного автопарку модельного логістичного підприємства **LogiTrans s.r.o.** (Кошице, Словаччина).

---

## 🚀 Основні можливості системи

1. **Інформаційна панель (Dashboard)**
   - 6 ключових KPI-показників автопарку (активні авто, в ремонті, витрати за поточний місяць, сумарний пробіг, середня витрата пального, вартість 1 км).
   - 4 динамічні графіки: динаміка місячних витрат за 12 місяців, структура витрат за категоріями, порівняння пробігу, середня витрата пального (l/100 km).
   - Оперативні віджети: найближчі терміни STK/EK, поточний ремонт, останні заправки та активні сповіщення.

2. **Облік та управління автомобілями (Vozidlá)**
   - Повний CRUD для 10 транспортних засобів (Škoda Octavia, Superb, VW Passat, Transporter, Ford Transit, Mercedes Sprinter, Toyota Corolla Hybrid, Dacia Dokker, Renault Master, Hyundai i30).
   - Детальний профіль автомобіля з історією заправок, ремонтів, техоглядів та витрат.
   - Захист цілісності: заборона зменшення пробігу, перевірка унікальності EČV та VIN, безпечне архівування замість каскадного видалення.

3. **Керування водіями (Vodiči)**
   - База даних водіїв, категорії прав (B, C, C+E), контакти, дати закінчення дії посвідчень.
   - Бізнес-правило: заборона закріплення одного активного автомобіля за кількома основними водіями одночасно.

4. **Облік заправок та розрахунок витрати пального (Tankovanie)**
   - Автоматичний розрахунок загальної вартості: `Celková cena = množstvo × cena/liter`.
   - Точний розрахунок фактичної витрати пального за послідовними показаннями одометра:
     $$\text{Spotreba (l/100 km)} = \frac{\text{množstvo paliva}}{\text{prejdené km}} \times 100$$
   - Валідація: блокування некоректного або регресивного введення пробігу.

5. **Централізований облік витрат (Náklady)**
   - 8 категорій: Palivo, Servis, Opravy, Poistenie, Pneumatiky, Diaľničné známky, Parkovné, Ostatné.
   - Запобігання подвійному обліку завдяки зв'язкам `sourceRef` та `sourceId`.

6. **Технічне обслуговування та ремонти (Údržba a servis)**
   - Облік ТО, замін мастила, ремонту двигунів, гальмівних систем.
   - Статуси: Naplánované, Prebieha (авто автоматично переводиться у «V servise»), Dokončené, Zrušené.

7. **Технічні та екологічні огляди (STK / EK / Poistenie)**
   - Автоматичний відлік днів до закінчення з колірною градацією:
     - 🟢 **Platné** (> 30 днів)
     - 🟡 **Blíži sa termín** (<= 30 днів)
     - 🔴 **Kritický termín** (<= 7 днів)
     - ⬛ **Po termíne** (прострочено)

8. **Центр сповіщень (Upozornenia)**
   - Автоматична генерація тривог про наближення термінів оглядів, закінчення страховок, високу витрату та затримки ремонту.
   - Позначення як прочитане, фільтрація, прямий перехід до картки авто.

9. **Аналітика та експорт звітів (Štatistiky a reporty)**
   - Порівняльний аналіз ефективності автопарку (€/km).
   - Експорт таблиць у **CSV** (з підтримкою словацьких діакритичних символів через UTF-8 BOM).
   - Друк / експорт у **PDF** із фірмовим заголовком підприємства та полями підписів.

10. **Налаштування та відновлення демо-даних (Nastavenia)**
    - Реквізити підприємства LogiTrans s.r.o.
    - Налаштування порогових значень сповіщень.
    - Кнопка швидкого відновлення вихідного стану демонстраційної бази.

## 🛠 Технологічний стек

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide React, SVG Charts.
- **Backend**: Node.js, Express REST API, tsx runner.
- **Database**: SQLite (`better-sqlite3`) у режимі WAL (Write-Ahead Logging) із підтримкою зовнішніх ключів та транзакцій.
- **Локалізація**: Словацька мова (sk-SK), валюта EUR (€), формат дат `DD.MM.YYYY`, часовий пояс `Europe/Bratislava`.

## ⚙️ Встановлення та запуск

### 1. Системні вимоги
- Node.js v20 або вище
- npm v10 або вище

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Запуск у режимі розробки
```bash
npm run dev
```
Сервер запуститься за адресою: `http://localhost:3000`. При першому запуску автоматично створюється файл бази даних `data/fleet.sqlite` та завантажується 10 автомобілів, 6 водіїв, понад 50 заправок і сервісних записів.

### 4. Запуск автоматизованих тестів
```bash
npm test
```
Виконує 10 обов'язкових перевірок бізнес-логіки: додавання автомобіля, унікальність EČV, розрахунок витрати пального за одометром, запобігання зменшенню пробігу, нарахування витрат та класифікація термінів STK.

### 5. Збірка для Production
```bash
npm run build
npm start
```
